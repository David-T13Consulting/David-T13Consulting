#### What's here

**[governed-ai-runtime](https://github.com/David-T13Consulting/governed-ai-runtime)**: a
governed AI assistant over a personal knowledge base, built as a working model for AI in
regulated industries. Data classification is enforced in code, answers cite their sources,
the model runs on the owner's machine with no cloud fallback, and failed answers are kept
locally for human review. A four-level data-sovereignty model for rented and cloud models
is designed, with the first EU-provider connection built. Built with Claude Code and Codex agents under one written
change-control protocol, with 706 automated tests. The status page says what is built and
what is still design.

**Home-nursing mobile prototype (code private).** Took a nurse-facing mobile app from user
research to a working prototype in five weeks, directing Claude Code as the delivery team:
interview findings became a prioritised backlog, then design, code and tests ran in short
loops with my approval at each step, followed by usability sessions with nurses on iPhone.
